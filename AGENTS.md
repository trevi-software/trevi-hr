# trevi-hr — AGENTS.md

## What this is

Odoo **14.0** addons repository for HR/Payroll modules by TREVI Software.
Generated from the [OCA addons-repo-template](https://github.com/OCA/oca-addons-repo-template.git) (copier v1.39).

## Repo layout

- Each subdirectory is a standalone Odoo addon module ([OCA convention](https://github.com/OCA/maintainer-tools))
- Each module has `__manifest__.py`, `__init__.py`, `models/`, `views/`, `tests/`, `security/`, `data/`
- The `setup/` directory and `requirements.txt` are auto-generated by `setuptools-odoo` — never edit manually

## External dependency

- `payroll` repo: `https://github.com/trevi-software/payroll` branch `14.0-trevi`

## Developer workflow

1. **Lint/format**: `pre-commit run --all-files` (configured in `.pre-commit-config.yaml`)
   - CI skips `oca-gen-addon-readme` (set via `SKIP` env var in pre-commit workflow)
   - `pylint_odoo` mandatory checks use `.pylintrc-mandatory`; optional checks use `.pylintrc`
   - Lint order implied by pre-commit: autoflake → black → prettier → eslint → trailing-whitespace → isort → flake8 → pylint_odoo
2. **Tests**: run inside OCA CI containers (`ghcr.io/oca/oca-ci/py3.6-odoo14.0:latest`)
   - `oca_install_addons` → `oca_init_test_database` → `oca_run_tests`
   - Tests use `odoo.tests.common.SavepointCase` or `payroll.tests.common.TestPayslipBase`
3. **Code style**:
   - Python: black (88 chars), isort, flake8 (bugbear), autoflake
   - JS: eslint (ecmaVersion 2019)
   - XML/others: prettier with `@prettier/plugin-xml`
   - `__init__.py` isort exclusions are intentional
4. **CI**: GitHub Actions on `14.0*` branches
   - Tests run against both Odoo and OCB containers
   - `.pot` updates pushed on push to `14.0` (requires `GIT_PUSH_TOKEN`)
   - Codecov integration enabled

## Conventions

- **Version**: all modules target `14.0.x.x.x` (validated by `pylint_odoo`)
- **License**: AGPL-3 per module (check individual `__manifest__.py`)
- **Author**: `TREVI Software` (required by pylint mandatory checks)
- **Manifest keys**: `license` is required; `description` and `active` are deprecated

## What NOT to do

- Do not manually edit `setup/` files or `requirements.txt` — they are auto-generated
- Do not edit `README.rst` directly — they are generated from `readme/` fragments by `oca-gen-addon-readme`
- Do not add `en.po` files (blocked by pre-commit)
