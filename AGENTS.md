# trevi-hr — AGENTS.md

## What this is

Odoo **16.0** addons repository for HR modules by TREVI Software. Generated from the
[OCA addons-repo-template](https://github.com/OCA/oca-addons-repo-template.git) (copier
v1.35).

## Repo layout

- Each subdirectory under repo root is a standalone Odoo addon module
- Each module has `__manifest__.py`, `__init__.py`, `models/`, `views/`, `tests/`,
  `security/`, `data/`
- `setup/` and `requirements.txt` are auto-generated by `setuptools-odoo` — never edit
  manually
- `README.rst` is generated from `readme/` fragments by `oca-gen-addon-readme` — edit
  fragments, not the `.rst`

## Developer commands

- **Lint/format**: `pre-commit run --all-files --show-diff-on-failure`
  - CI skips `oca-gen-addon-readme` (via `SKIP` env var)
  - `pylint_odoo` mandatory checks use `.pylintrc-mandatory`; optional checks use
    `.pylintrc` with `--exit-zero`
- **Tests**: run inside OCA CI containers (`ghcr.io/oca/oca-ci/py3.10-odoo16.0:latest`)
  - `oca_install_addons` → `oca_init_test_database` → `oca_run_tests`
  - Tests use `odoo.tests.common.TransactionCase` or `SavepointCase`

## Code style

- Python: black (88 chars), isort (`known_odoo`/`known_odoo_addons` sections), flake8
  with bugbear, autoflake (remove unused imports), pyupgrade (`--keep-percent-format`)
- JS: eslint (ecmaVersion 2019, globals: `odoo`, `owl`, `luxon`, etc.)
- XML/others: prettier (`@prettier/plugin-xml`, `xmlWhitespaceSensitivity: strict`,
  `bracketSpacing: false`)
- `fix-encoding-pragma --remove` removes `# -*- coding: utf-8 -*-`
- `__init__.py` excluded from isort intentionally
- `en.po` files are forbidden (blocked by pre-commit)

## Conventions

- **Version**: `16.0.x.x.x` validated by `pylint_odoo`
- **License**: AGPL-3 per module (check individual `__manifest__.py`; allowed: AGPL-3,
  GPL-2, GPL-3, LGPL-3)
- **Author**: must be `TREVI Software` (enforced by mandatory pylint)
- **Manifest**: `license` key required; `description` and `active` deprecated
- **CI**: GitHub Actions on `16.0*` branches; tests run against both Odoo and OCB
  containers; Postgres 12
